# Hello World

Bienvenue dans l'exercice Hello World, sur le parcours Python d'Exercism.
Si tu as besoin d'aide pour exécuter les tests ou soumettre ton code, consulte `HELP.md`.

## Instructions

L'exercice d'introduction classique.
Dis simplement « Hello, World! ».

[« Hello, World! »][hello-world] est le premier programme traditionnel pour débuter la programmation dans un nouveau langage ou environnement.

Les objectifs sont simples :

- Modifie le code fourni pour qu'il produise la _string_ « Hello, World! ».
- Lance la suite de tests et assure-toi qu'elle réussit.
- Soumets ta solution et vérifie-la sur le site web.

Si tout se passe bien, tu pourras récupérer ton premier véritable exercice.

[hello-world]: https://en.wikipedia.org/wiki/%22Hello,_world!%22_program
